  主流方案有几种：

  | 方案                  | 做法                         | 优点        | 缺点           |
  |---------------------|----------------------------|-----------|--------------|
  | Tool Calling (当前方案) | 提示词描述能力 + 工具查询图谱           | 灵活、数据实时   | 依赖模型理解提示词    |
  | Schema 注入           | 把图谱 Schema（节点类型、关系类型）放进提示词 | 模型更了解数据结构 | 提示词变长        |
  | Few-shot 示例         | 在提示词中给查询示例                 | 模型学得快     | 占用 token     |
  | RAG + 图谱            | 先用向量检索相关子图，再让模型分析          | 精准        | 复杂度高         |
  | Text2Cypher         | 模型直接生成 Cypher 查询           | 强大        | 需要模型懂 Cypher |
